AOP

Installation

Local-first agent orchestration for macOS, Linux, and Windows. Pick a prebuilt binary or install from source with Bun (contributors and latest main).

MACOS · LINUX · WINDOWS
$ curl -fsSL https://getaop.com/install.sh | sh

Downloads the compiled aop binary (CLI + local-server + dashboard). Requires Git and an agent CLI for runs.

$ git clone https://github.com/get-aop/aop-mono.git cd aop-mono && ./install

Installs from source: bun install, links aop, builds the dashboard, and registers the local-server user service.

DL> https://getaop.com/latest/aop-windows-x64-setup.exe

Desktop setup installer (aop-windows-x64-setup.exe) — installs the AOP desktop app. Unsigned in alpha: SmartScreen may warn (More info → Run anyway).

PS> irm https://getaop.com/install.ps1 | iex

CLI-only install via PowerShell (prebuilt aop-windows-x64.exe + runtime assets under %LOCALAPPDATA%\aop).
WSL users: run the Linux curl command inside your distro instead — AOP runs the sidecar in-distro.
