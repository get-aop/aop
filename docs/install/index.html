AOP

Installation

Install the AOP host on a Mac or Linux computer, then connect to it from the desktop app on macOS or Windows, or from any browser. Contributors can install from source with Bun.

HOST: MACOS · LINUX | APP: MACOS · WINDOWS
$ curl -fsSL https://getaop.com/install.sh | sh

One command installs the aop binary and its dashboard, puts aop on your PATH, and starts the host as a background service (launchd on macOS, systemd on Linux). Requires Git, the GitHub CLI signed in, and Claude Code signed in on that machine. To install without starting the service, add --no-service.

Windows cannot run the host. Install it on a Mac or Linux computer and use the desktop app from Windows.

$ git clone https://github.com/get-aop/aop.git cd aop && ./install

Installs the host from source on macOS or Linux: bun install, links aop, builds the dashboard, and registers the local-server user service.

DL> https://getaop.com/latest/aop-macos-arm64.dmg
DL> https://getaop.com/latest/aop-macos-x64.dmg
DL> https://getaop.com/latest/aop-windows-x64-setup.exe

A client of your AOP host: enter the host's https:// address and a pairing code (run aop pair on the host to get one). The macOS app comes in Apple silicon (arm64) and Intel (x64) builds, and can also run the host on that Mac. The Windows app starts no server.

The macOS app is signed and notarized. The Windows app is not signed yet: SmartScreen says "Windows protected your PC" the first time, so choose More info, then Run anyway.
