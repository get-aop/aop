# AOP product tour

Short walkthroughs of the dashboard. Each page covers one operator action: what you see, why it helps, and how to try it yourself.

![AOP dashboard](../screenshots/hero.png)

The tour shows the core AOP loop: open a session, describe the work (or arm a workflow), watch the run in the terminal dock, and hand off through a pull request.

| Stage | Feature | What it replaces |
|-------|---------|------------------|
| Start | [New session](./new-session.md) | Blank prompts with no context |
| Start | [Attach a repository](./attach-repository.md) | Remembering repo paths and git state |
| Run | [Run a workflow](./run-workflow.md) | Chaining implementation, tests, review, and debug skills by hand |
| Setup | [Edit workflows](./workflow-edit.md) | Treating the default agent process as a black box |
| Observe | [Terminal dock](./terminal-dock.md) | Watching several terminal windows at once |
| Handoff | [Create PR](./create-pr.md) | Manual branch push and PR description work |
