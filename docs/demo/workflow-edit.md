# Edit workflows

![AOP dashboard](https://raw.githubusercontent.com/get-aop/aop/main/docs/screenshots/hero.png)

## What you see

Settings → **Workflows** lists every workflow with its step sequence. Simple workflows expand inline: rename the workflow, then edit each step's kind (Implement, Code review, Test, Browser check), provider, model, thinking level, and Fast mode. A fixed footnote explains the auto-debug helpers.

## Why it matters

- **No visual graph needed** — the linear editor covers the built-in step kinds directly.
- **Seed included** — first open with no user workflows seeds **Ship it** automatically.
- **Legacy preserved** — anything that doesn't match the simple shape stays runnable as-is.

## How to try it

1. Open **Settings → Workflows**.
2. Expand **Ship it** (or any user workflow) and change a step's model or thinking.
3. Add a step from the four kinds (up to eight total) and save.
4. Type `#workflow` in a session to confirm the updated steps in the rail.
