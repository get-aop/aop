# New session

![AOP dashboard](https://raw.githubusercontent.com/get-aop/aop/main/docs/screenshots/hero.png)

## What you see

A fresh session shows the draft hero: a centered **aop** wordmark above the composer, with four suggestion chips — **Implement a feature**, **Review a pull request**, **Debug failing tests**, and **Run “Ship it”**. The first three prefill the composer; **Run “Ship it”** also arms the seeded workflow in the rail.

## Why it matters

- **One clear starting point** — the composer is ready before you type anything.
- **Fast prompts** — common intents are one click away.
- **Workflow first** — you can arm a workflow before sending, so the run starts with a plan instead of a single-shot turn.

## How to try it

1. Press **⌘N** (or the **New session** row in the rail) and pick a repository.
2. Click **Debug failing tests** and watch the text appear in the composer.
3. Or click **Run “Ship it”** to prefill the prompt and arm the workflow.
4. Press **Enter** to start the run.
