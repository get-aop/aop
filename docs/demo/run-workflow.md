# Run a workflow

![AOP dashboard](https://raw.githubusercontent.com/get-aop/aop/main/docs/screenshots/hero.png)

## What you see

Type `#workflow` in the composer to open the workflow picker — each option shows its step sequence inline. Selecting one arms the rail: workflow name, step chips (step icon, provider mark, model, effort, Fast), and × to clear. Hovering a step shows its full provider, model, effort, and Fast setting.

## Why it matters

- **One renderer** — the steps you pick match the glyphs in Settings, the picker, and task detail.
- **Legacy safe** — legacy workflows show “N steps · Legacy” and run exactly as defined.
- **Always visible** — the rail keeps the armed workflow in view until you send or clear it.

## How to try it

1. Open a session in a repository.
2. Type `#workflow`, pick **Ship it** (or any saved workflow).
3. Review the step chips in the rail; hover one for the full detail.
4. Send a message — the run starts with the workflow's steps.
