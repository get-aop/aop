# Attach a repository

## What you see

With no repositories registered, the rail shows an empty state: **No repositories yet** with an **Attach a repository** button. The attach dialog browses your file system — git repositories get a `⎇ git` badge with the current branch, plain folders descend, and the footer shows the selected path.

## Why it matters

- **Fresh install, no blank rail** — the first-run path tells you exactly what to do.
- **Repo scope** — sessions, scope chips, and tags are all organized per repository.
- **Visible git state** — you attach a repository, not a folder that happens to contain one.

## How to try it

1. Start AOP with a clean `~/.aop-dev` profile.
2. Click **Attach a repository** in the rail.
3. Navigate to a git checkout; confirm the `⎇ git` badge and branch name.
4. Click **Attach repository** — the repo appears under Projects with its own scope chip.
