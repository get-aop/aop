# AOP brand assets

Canonical logo mark for AOP (dashboard, landing site, favicons, install page).

- **`aop-logo-mark.svg`** — three pool bubbles on a rounded square. Used by:
  - `apps/dashboard/src/components/brand/AopLogoMark.tsx`
  - `aop-web/components/brand/AopLogoMark.tsx` (keep in sync)

When updating the mark, edit this SVG first, then sync the React components and `aop-web/app/icon.svg`.
